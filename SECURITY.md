# Security policy

This policy covers this repository, a project of Northflow Technologies AS.

## Reporting a vulnerability

Please do not report security problems in public issues. Use one of these:

- **GitHub:** the "Report a vulnerability" button under the repository's Security tab (private vulnerability reporting).
- **Email:** hello@northflow.no, with "Security" in the subject.

Include what you found, how to reproduce it, and the version or commit it affects. We confirm receipt within two working days and keep you informed until the issue is resolved. We credit reporters in the release notes unless you prefer otherwise.

## Supported versions

Security fixes go into the latest release of each project.
