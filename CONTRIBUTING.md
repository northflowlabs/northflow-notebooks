# Contributing

Thank you for helping. These notes apply to this repository, a project of Northflow Technologies AS.

## Before you start

- **Questions and ideas:** open an issue and describe what you want to do. For larger changes, agree on the approach in the issue before writing code.
- **Bugs:** open an issue with a minimal example, what you expected and what happened.
- **Security problems:** see [SECURITY.md](SECURITY.md); never in a public issue.

## Pull requests

- Keep each pull request to one change, with tests for new behaviour and fixed bugs.
- Run the repository's checks locally before pushing (see its README or CI workflow).
- Describe what changes and how you checked it.
- Update the CHANGELOG when the repository has one.

By contributing, you agree that your contribution is licensed under the repository's licence.

## Code of conduct

Everyone taking part follows our [code of conduct](CODE_OF_CONDUCT.md).
